## Assessed PVT dataset — not yet imported

Chuqin Xiang, Xinrui Fan, Duo Bai, Ke Lv, Xu Lei. *A Resting-state EEG Dataset for
Sleep Deprivation*. OpenNeuro, **ds004902, version 1.0.8**.
[Version DOI](https://doi.org/10.18112/openneuro.ds004902.v1.0.8).
The pinned dataset metadata declares **CC0**, recorded here as **CC0-1.0**.
[Declaration](https://raw.githubusercontent.com/OpenNeuroDatasets/ds004902/1.0.8/dataset_description.json)
and [CC0 terms](https://creativecommons.org/publicdomain/zero/1.0/).

Related paper: Xiang, C., Fan, X., Bai, D. et al. *A resting-state EEG dataset for
sleep deprivation*. Scientific Data 11, 427 (2024).
[Publication DOI](https://doi.org/10.1038/s41597-024-03268-2).

Upstream funding acknowledgement: National Key Research and Development Program
of China (2021YFC2501500). No author endorsement of HAL2030 is implied.
Only source metadata, file hashes, and assessment results are included here;
participant responses and EEG recordings are not shipped.

## Project-generated data

`data/telemetry_10min.csv` is deterministic synthetic data generated by HAL2030.
It is not sourced from OpenNeuro. See [source registry](data/sources.json) and
[provenance policy and dataset assessment](docs/DATA_PROVENANCE.md).

The family-message demo media under `static/family-media/` are synthetic
project assets. The fictional narration uses Windows speech synthesis.
See the [demo guide](docs/FAMILY_MESSAGE_DEMO.md) for generation details.

## Optional LivePortrait benchmark

The offline family-message CLI uses [LivePortrait](https://github.com/KlingAIResearch/LivePortrait) by Kuaishou Visual Generation and Interaction Center at commit `9b294b3d0536135442ea73cb01e6cb3ca7029dd3`. Install the [upstream checkpoints](https://huggingface.co/KlingTeam/LivePortrait) separately. The app and executable do not bundle the upstream code or weights.
